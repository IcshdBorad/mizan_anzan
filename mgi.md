# Mizan Genius Index (MGI)

## Purpose

MGI is the monthly composite index used to identify qualified high-level performance across multiple dimensions.

It is not simply the highest raw score.

## Target weighting

| Dimension | Weight |
|---|---:|
| Performance | 30% |
| Accuracy | 25% |
| Consistency | 20% |
| Speed | 15% |
| Progress | 10% |

Total: 100%.

## Eligibility gate

The target model includes minimum participation and quality requirements before a participant can be considered.

Examples used by the approved plan:

- Minimum sessions
- Minimum questions
- Multiple training days
- Minimum accuracy
- Minimum qualified participant population

The exact thresholds must remain configurable and versioned.

## Comparability

Raw values from different difficulty levels should not automatically be treated as equivalent.

Where appropriate, the calculation should normalize or percentile-transform comparable performance dimensions before combining them.

## Transparency

A published Monthly Genius result should expose enough information to explain the decision without exposing private data.

Example:

```text
MGI 94.72 / 100
Performance 95.4
Accuracy 96.2
Consistency 93.8
Speed 91.7
Progress 88.4
```

## Important limitation

MGI must not claim to measure intelligence in a clinical or psychometric sense. It is a MIZAN performance index for the defined training/competition environment.
