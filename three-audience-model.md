# Three-Audience Experience

## 1. Genius

Purpose: motivation, ownership and visible progress.

Should emphasize:

- current level
- progress
- achievements
- consistency
- training journey
- personal milestones

The Genius should feel that the platform represents a personal journey, not a table position.

## 2. Parent

Purpose: informed support.

Should emphasize:

- current level
- development trend
- general strengths
- broad areas for growth
- training consistency
- attendance/activity

The Parent should not be given every professional diagnostic or training decision.

## 3. Coach

Purpose: interpretation and educational decision-making.

Should emphasize:

- deeper performance analysis
- recurring performance patterns
- response speed
- skill-level comparisons
- operation-level patterns
- training-support indicators

The Coach remains the decision-maker.

## Core principle

```text
Platform = Transparency
Parent   = Follow-up and Support
Coach    = Interpretation and Educational Decision
Genius   = Center of the Process
```

## Product boundary

MIZAN is an extension of the coach's work, not a replacement for the coach.
