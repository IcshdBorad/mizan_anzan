# MIZAN Leaderboard Framework

## Principle

MIZAN should not define one universal leaderboard criterion as the only measure of excellence.

Different students can demonstrate excellence through different dimensions.

## Recommended criteria

1. Overall
2. Accuracy
3. Speed
4. Consistency
5. Progress
6. Points

## Recognition examples

- Overall Leader
- Accuracy Champion
- Speed Champion
- Consistency Champion
- Rising Genius
- Points Leader

## Why multiple criteria matter

A single raw score can over-reward one unusually strong session and does not fully describe sustained performance.

Leaderboards should therefore be explicit about the criterion being used.

## Integrity

A leaderboard must state its:

- population
- time period
- eligibility rules
- scoring criterion
- tie-break rules
- data freshness

The system must never present an unclear ranking as an objective statement of overall ability.
