# Recommended Implementation Order

The following order minimizes rework.

## Phase 1 — Foundation

1. Database migration
2. Entity model
3. Branch model
4. Genius Code
5. Parent Code
6. Coach Code
7. Relationship records
8. Permission/scope layer

## Phase 2 — Competition

9. Multi-criteria leaderboard
10. Eligibility engine
11. MGI calculation
12. Monthly Genius recognition
13. Recognition categories
14. Publication/audit status

## Phase 3 — Dashboards

15. Genius dashboard
16. Parent dashboard
17. Coach dashboard
18. Entity dashboard

## Phase 4 — Data depth

19. Record question-level answers
20. Record response times
21. Record technique/skill metadata
22. Build reliable recurring-error analysis

## Phase 5 — MIZAN Core

23. Extract shared identity
24. Extract shared analytics
25. Extract shared competition services
26. Connect future engines

## Important

Do not claim that a feature is production-ready merely because its UI exists. Each feature needs a server-side authorization path and a data model that actually supports the displayed information.
