# Roles and Permissions

## Core roles

### Genius
Sees personal progress, achievements, training history and motivational indicators.

### Parent
Sees the child's general progress, consistency, attendance/training activity, broad strengths and development direction.

### Coach
Sees deeper performance analytics, patterns, comparisons within the authorized scope and training-support information.

### Entity
Manages authorized coaches, branches and geniuses within its organizational scope.

### Admin
Manages system-level configuration and authorized administrative operations.

## Educational boundary

The platform should not turn the Parent dashboard into a tool for supervising the Coach.

The platform provides evidence.

The Parent provides support.

The Coach interprets and decides.

The Genius remains the center of the learning process.

## Governing principle

> The platform reveals the path; the coach shapes the path.

Arabic product principle:

> المنصة تكشف المسار، والمدرب يصنع المسار.

## Permission rule

Access should be evaluated from:

`Identity + Role + Relationship + Permission + Scope`

A public code alone must never be treated as sufficient authorization.
